# Life OS Privacy Policy

Last updated: August 30, 2026

Life OS is an open-source, self-hosted personal operating system. Each user runs their own private instance and chooses which integrations and data sources to connect.

## Data Life OS may process

Depending on the integrations a user enables, Life OS may process personal goals, check-ins, notes, meal logs, fitness activity, sleep summaries, readiness information, calendar events, and other information the user explicitly provides or authorizes.

For an Oura connection, Life OS requests only the scopes shown during authorization. The initial integration uses the `daily` scope to read daily sleep, activity, and readiness summaries.

## How data is used

Life OS uses connected data only to provide the user's requested planning, tracking, accountability, and progress-analysis features. Life OS does not sell personal data or use health data for advertising.

## Storage and sharing

The open-source Life OS project does not operate a centralized user-data service. In a self-hosted installation, personal data and integration credentials are stored in the user's private environment. Users are responsible for securing their installation and any devices, servers, backups, or third-party services they connect.

Life OS does not place credentials, access tokens, or private health records in the public source repository. Data is shared with third parties only when the user enables an integration or explicitly requests an external action.

## Retention and deletion

Users control retention in their private installation. They can disconnect an integration, revoke access with the connected provider, and delete locally stored credentials or records at any time.

## Third-party services

Connected services such as Oura, Apple, Google, and OpenAI process information under their own privacy policies. Life OS only accesses the data and permissions a user authorizes.

## Contact

For privacy questions, open an issue in the [Life OS repository](https://github.com/pujagorai9/life-os/issues).
